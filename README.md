# ⚡ СТРУМ — сайт оренди, продажу та збірки електробайків

Односторінковий адаптивний сайт для вигаданої компанії. Оренда, продаж, кастомні збірки й сервіс електробайків.

> Демонстраційний проєкт для портфоліо: бренд, ціни й контакти вигадані, ілюстрації байків намальовані кодом (SVG).

## Що вміє сайт

- **Каталог моделей** з фільтром «Місто / Бездоріжжя» і характеристиками. Кожна картка малює свій SVG-байк у кольорі моделі.
- **Калькулятор оренди**: модель, кількість днів (повзунок), знижки від 3 і 7 днів, додаткові опції, застава.
- **Конфігуратор збірки**: рама, мотор, батарея, колір, опції. Ціна, швидкість і запас ходу перераховуються одразу, а прев'ю байка змінює колір і тип.
- **Форма заявки**: валідація телефону, автозаповнення з калькулятора та конфігуратора, чернетка в `localStorage`.
- Анімації появи при прокручуванні, біжучий рядок, підсвічування меню поточної секції, FAQ-акордеон на `<details>`.
- Адаптивна верстка (ПК, планшет, телефон) і бургер-меню. Враховано `prefers-reduced-motion`.

## Технології

HTML5, CSS3 (Grid, Flexbox, custom properties, `color-mix`, анімації), Vanilla JavaScript (IntersectionObserver, делегування подій), SVG.

## Запуск

Відкрий `index.html` у браузері. Нічого збирати не потрібно.
